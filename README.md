## about

**Jadoo is a modern, responsive travel agency landing page built with React and Tailwind CSS.**\
The layout is based on this original [Figma design](https://www.figma.com/community/file/993910904620677970) and includes several improvements such as a mobile-first structure, refined UI details, subtle Motion animations, and system-based dark mode support using the user's `prefers-color-scheme`.

The page is statically generated (SSG) using [Vike](https://vike.dev/), which provides fast performance and SEO-friendly rendering.
This project helped me practice building clean, reusable components and translating a design into a functional interface with attention to user experience.

## tech stack

This project uses a lightweight, modern front-end setup with React components, Tailwind utility classes, smooth animations powered by Motion, and Vike for static generation and SEO.

## getting started

To run the project locally, make sure you have [Node.js](https://nodejs.org/en/) installed along with a package manager such as [pnpm](https://pnpm.io/installation).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/laianesuzart/landing-page.git
   ```
2. Navigate to the project directory:
   ```bash
   cd landing-page
   ```
3. Install dependencies:
   ```bash
   pnpm install
   ```
4. Start the development server:
   ```bash
   pnpm run dev
   ```
The application will be available at the URL shown in your terminal.
